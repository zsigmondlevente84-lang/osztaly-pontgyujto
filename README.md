# Osztály-pontgyűjtő 🌟

Egyoldalas, szerver nélküli webes alkalmazás: a tanár pontokat adhat az osztály tanulóinak (csak becenevekkel).

- Megjelenés: kisállatok, virágok vagy színes formák
- Jutalom-animáció: konfetti, virágszirom-eső vagy csillagfény
- Világ: ösvény a kastélyhoz, fára mászás, erdei bogyógyűjtés
- Napi összesítő, új nap, export/import JSON
- Az adatok csak a böngészőben maradnak (localStorage)

Használat: nyisd meg az `index.html`-t böngészőben, vagy a GitHub Pages linket.
